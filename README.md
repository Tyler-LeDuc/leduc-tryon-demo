# Leduc Try-On — Live Demo

Real-time AR makeup try-on in the browser: lips, eyes, cheeks, skin, brows and hair, on a live camera or an uploaded photo.

**Try it:** https://tyler-leduc.github.io/leduc-tryon-demo/

This repository hosts only the public demo page and a minified build of the engine. The source code is proprietary.
